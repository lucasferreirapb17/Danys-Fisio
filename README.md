# Dany's Fisio — Landing Page

Landing page institucional desenvolvida para o Centro de Fisioterapia Dany's,
clínica real em funcionamento no Rio de Janeiro (unidades em Realengo e Bangu).

🔗 Site no ar: https://lucasferreirapb17.github.io/Danys-Fisio/

## Sobre o projeto
Projeto real, fora do contexto de curso, desenvolvido para apoiar a divulgação
e captação de pacientes da clínica onde atuo como fisioterapeuta. A página foi
estruturada para comunicar credibilidade, informar convênios aceitos,
localização das unidades e facilitar o agendamento via WhatsApp.

## Funcionalidades
- Seção hero com chamada para ação e agendamento direto via WhatsApp (link com mensagem pré-preenchida)
- Seção de convênios atendidos, com logos das operadoras
- Seção "Onde estamos", com mapas do Google incorporados para as duas unidades
- FAQ em formato acordeão usando os elementos nativos `<details>` e `<summary>` do HTML — sem depender de JavaScript
- Integração com Google Tag Manager para acompanhamento de métricas de acesso
- SEO on-page: meta description, Open Graph tags, favicon próprio
- Layout responsivo

## Tecnologias
- HTML5 semântico
- CSS3
- Google Tag Manager

## Por que esse projeto importa
Foi meu primeiro projeto aplicado a um negócio real, não a um exercício de curso.
Precisei lidar com informações que tinham que estar corretas, integração com
WhatsApp pensada para conversão de pacientes, e cuidado com a primeira
impressão que o site passa a alguém buscando atendimento.
